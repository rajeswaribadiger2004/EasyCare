# EasyCare
Easy Care – A Telemedicine Portal with Offline Accessibility. It's an innovative telemedicine portal designed to ensure seamless healthcare access, even in low-connectivity areas. This project, which won a "-----National-level hackathon at AIET Mangalore-----".

Key Features:
✅ Multi-language support – Patients can access healthcare services in their preferred language.
✅ Online health consultation – Enables doctor-patient interaction through a streamlined web platform.
✅ Video conferencing – Facilitates real-time virtual consultations for effective diagnosis.
✅ Offline emergency access via SMS – The standout feature, allowing users to reach doctors without internet. Using predefined keypad numbers, patients can send an SMS alert, ensuring immediate medical attention.

Technical Implementation:
✔ Front-End Technologies: HTML, CSS, SQL , JavaScript (for a responsive and interactive UI)
✔ API Integration: Connected APIs for video conferencing, online consultations, and SMS-based emergency services
✔ SMS Gateway Integration: Enabled offline accessibility for emergency medical assistance
✔ AI based Chatbot:Dveloped AI based health Chatbot for any queries
✔ Authentication & Data Security – Ensuring confidentiality in medical consultations
